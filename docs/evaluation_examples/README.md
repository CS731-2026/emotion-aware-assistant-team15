# Evaluation Examples

This folder contains sanitized examples for the `/llm-compare` manual scoring and export workflow. They are small synthetic records, not live provider output.

The final LLM comparison used an LLM-as-a-judge evaluation with human supervision. The final evidence files are stored in `docs/evaluation/llm_comparison_final/`.

Real comparison runs are saved locally under ignored runtime directories. Do not commit local evaluation logs unless they have been reviewed, sanitized, and intentionally copied here.
